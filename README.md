# 🚀 IVAC SMS & OTP Automation Ecosystem (Self-Hosted)

একটি সম্পূর্ণ স্বাধীন, নিজস্ব নিয়ন্ত্রণে পরিচালিত অ্যান্ড্রয়েড এসএমএস অটোমেশন ইকোসিস্টেম। এখানে কোনো প্রকার থার্ড-পার্টি অ্যাপ (যেমন **MacroDroid**) বা থার্ড-পার্টি টানেলিং সার্ভিস (যেমন **ngrok**) প্রয়োজন নেই।

---

## 🗂️ সম্পূর্ণ ডিরেক্টরি কাঠামো (Project Structure)

```text
c:\microdroidpro\
├── 1_start_server.bat            # [১] নোড জেএস ব্যাকএন্ড সার্ভার চালু করার ফাইল
├── 2_open_dashboard.bat          # [২] ব্রাউজারে লাইভ ওটিপি ড্যাশবোর্ড খোলার ফাইল
├── 3_start_python_listener.bat   # [৩] পাইথন অটো-টাইপার ও ক্লিপবোর্ড স্ক্রিপ্ট চালু
├── 4_build_release_apk.bat       # [৪] অ্যান্ড্রয়েড ফোনের জন্য Release APK তৈরি
├── 5_send_test_sms.bat           # [৫] ফোন ছাড়াই নকল IVAC মেসেজ পাঠিয়ে টেস্ট
├── 6_run_phone_via_usb.bat       # [৬] USB ক্যাবল দিয়ে ফোনে সরাসরি অ্যাপ রান
│
├── server\                       # নোড জেএস ব্যাকএন্ড ও লাইভ ওয়েব ড্যাশবোর্ড
│   ├── package.json              # Express, ws, cors ডিপেন্ডেন্সি
│   ├── server.js                 # HTTP POST (/ivac-sms) এবং WebSocket ব্রডকাস্টার
│   ├── render.yaml               # Render.com ক্লাউডে ১-ক্লিকে ২৪ ঘণ্টা লাইভ ডেপ্লয়মেন্ট
│   ├── Dockerfile                # ডকার কনটেইনার কনফিগারেশন
│   └── public\
│       ├── index.html            # ড্যাশবোর্ড UI (বড় ওটিপি হাইলাইট কার্ড ও হিস্ট্রি)
│       ├── style.css             # প্রিমিয়াম ডার্ক নিয়ন থিম
│       └── app.js                # রিয়েল-টাইম WebSocket ও অডিও অ্যালার্ট লজিক
│
├── python-client\                # পাইথন অটোমেশন ও ওটিপি টাইপার স্ক্রিপ্ট
│   ├── requirements.txt          # পাইথন লাইব্রেরি
│   ├── otp_autofill.py           # অটো-টাইপ ও ক্লিপবোর্ড সিঙ্ক স্ক্রিপ্ট
│   └── mock_test_sms.py          # টেস্ট মেসেজ পাঠানোর স্ক্রিপ্ট
│
└── android-sms-forwarder\        # ফ্লাটার অ্যান্ড্রয়েড অ্যাপ (MacroDroid বিকল্প)
    ├── pubspec.yaml              # ডিপেন্ডেন্সি
    ├── android\                  # নেটিভ অ্যান্ড্রয়েড বিল্ড ও গ্র্যাডল ফাইল
    │   └── app\src\main\
    │       └── AndroidManifest.xml # ব্যাকগ্রাউন্ড সার্ভিস ও এসএমএস পারমিশন
    └── lib\
        ├── main.dart             # মোবাইল অ্যাপ UI ও টেস্ট ইন্টারফেস
        └── background_service.dart # 24/7 ব্যাকগ্রাউন্ড এসএমএস লিসেনার ও ফরওয়ার্ডার
```

## ⚡ কীভাবে চালাবেন (১ থেকে ৫ পর্যন্ত ফাইলগুলোতে শুধু ডাবল-ক্লিক করুন):

| ধাপ | ফাইল | কাজ |
|---|---|---|
| **১** | **`1_start_server.bat`** | ব্যাকএন্ড সার্ভার চালু করে (Port: 3000) |
| **২** | **`2_open_dashboard.bat`** | ব্রাউজারে সুন্দর ড্যাশবোর্ডটি ওপেন করবে |
| **৩** | **`3_start_python_listener.bat`** | ওটিপি স্বয়ংক্রিয়ভাবে ক্লিপবোর্ডে কপি ও ভিসা বক্সে টাইপ করবে |
| **৪** | **`4_build_release_apk.bat`** | যেকোনো ফোনে ইনস্টল করার জন্য APK ফাইল বানিয়ে দেবে |
| **৫** | **`5_send_test_sms.bat`** | আসল ফোন ছাড়াই কম্পিউটারেই টেস্ট ওটিপি পাঠাবে |

## 🌍 যেকোনো স্থান বা যেকোনো ফোন থেকে চালানোর উপায়:

### ১. ঘরের লোকাল ওয়াইফাইয়ের ভেতরে:
আপনার ফোনের অ্যাপে কম্পিউটারের লোকাল আইপি সেট করুন:
```text
http://192.168.31.140:3000/ivac-sms
```

### ২. পৃথিবীর যেকোনো প্রান্ত থেকে (সিমের মোবাইল ডেটা/ইন্টারনেট দিয়ে):
সার্ভারটি ২৪ ঘণ্টা ফ্রিতে ইন্টারনেটে লাইভ রাখতে:
1. `server` ফোল্ডারটিকে **[Render.com](https://render.com)** এ ডিপ্লয় করুন (প্রজেক্টে ইতিমধ্যে `render.yaml` ও `Dockerfile` রেডি আছে)।
2. রেন্ডার আপনাকে একটি পাবলিক লিংক দেবে (যেমন: `https://my-ivac.onrender.com`)।
3. মোবাইল অ্যাপে গিয়ে সার্ভার URL হিসেবে দিন:
   ```text
   https://my-ivac.onrender.com/ivac-sms
   ```
4. ব্যাস! এখন বিশ্বের যেকোনো দেশের যেকোনো ফোন থেকে এসএমএস আসা মাত্রই তা সাথে সাথে আপনার কম্পিউটারে চলে আসবে!
